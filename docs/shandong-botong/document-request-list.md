> **★ All documents (PI, Commercial Invoice, Packing List, export declaration, Certificate of Origin) MUST use HS Code `7608.20` (aluminium alloy tubes and pipes).**

> The Korea–China FTA Certificate of Origin issued under HS 7608.20 is required for duty-free import clearance in Korea. A different HS code invalidates the preferential tariff.
