## ⚠️ 최우선 유의사항 — HS Code 7608.20

> **모든 서류(견적서 · Commercial Invoice · Packing List · 수출신고 · 원산지증명서)의 HS Code를 반드시 `7608.20` (알루미늄 합금관, Aluminium alloy tubes and pipes)으로 통일해야 함.**
>
> - 한-중 FTA **원산지증명서(C/O)가 HS 7608.20으로 발급되어야만** 수입 통관 시 협정세율 적용(면세)이 가능함.
> - 공급사가 다른 HS(예: 7604 봉/형재, 7616 기타 알루미늄 제품)로 신고하면 C/O를 제출해도 세율 혜택을 받지 못하거나 통관이 지연됨.
> - 견적/PI 단계부터 Lawrence에게 HS 7608.20 사용을 서면으로 확약받을 것.
> - φ450·φ460이 외주 생산일 가능성이 있으므로(아래 기술 검토 참조), **외주 생산 시에도 Botong 명의로 C/O 발급이 가능한지** 사전 확인 필요.

## 7. 기술 검토 (DOHO 자체 판단)

- Botong 보유 최대 프레스는 2,300톤급 → 빌렛 직경 추정 230~254mm 이하. 당사 규격 φ450·φ460은 약 2배로 **자사 압출기 생산 불가로 추정**.
- 따라서 φ450/φ460 견적가는 외부 조달가일 가능성이 있음.
- **방문/협의 시 확인**: 보유 프레스 실물 톤수와 컨테이너 직경, 당사 규격의 실제 생산 공장.
- 외주 생산으로 확인될 경우: MTC 발행 주체, C/O 발급 가능 여부(HS 7608.20), 품질 책임 소재를 서면으로 정리할 것.
- 외피 규격은 φ460 × 8이 확정 규격 — 기존 견적서(φ461 기준)와 상이하므로 재견적 시 반드시 정정할 것.
